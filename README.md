# manual-assets

노션 업무매뉴얼에 넣는 화면 이미지 보관용 저장소입니다.

> **공개 저장소입니다.** 한 번 올린 이미지는 지워도 커밋 기록에 남아 누구나 볼 수 있습니다. 올리기 전 확인이 전부입니다.

## 올리기 전 처리 (필수)

아래 항목이 보이면 잘라내거나 흰색으로 가립니다.

| 가릴 것 | 예시 |
| :--- | :--- |
| 거래처 정보 | 상호, 대표자명, 사업자번호, 채널명 |
| 직원 정보 | DM 목록의 이름, 프로필 사진 |
| 대화 내용 | 메뉴 뒤로 비치는 메시지, 공지 본문 |
| 계정·연락처 | 이메일, 전화번호, 계좌 |

1. 필요한 부분만 남기고 자릅니다.
2. 남은 영역 중 위 항목을 가립니다.
3. **가린 결과를 담당자에게 보여주고 확인을 받은 뒤** 커밋합니다.

## 폴더 구조

```
images/
  <노션 페이지 이름>/
    01_<화면 설명>.png
    02_<화면 설명>.png
```

- 폴더명은 노션 페이지 이름과 같게 씁니다. (예: `images/채널이 목록에 안 보일 때/`)
- 파일명 앞 번호는 페이지의 단계 번호(1️⃣ 2️⃣)와 맞춥니다.
- 이미지를 바꿀 때는 같은 파일명으로 덮어씁니다.

## 노션에 넣는 방법

커밋 후 아래 주소를 노션 이미지로 넣습니다. 노션이 이미지를 내려받아 자체 저장합니다.

```
https://raw.githubusercontent.com/4dium-tax/manual-assets/main/images/<폴더>/<파일명>
```
